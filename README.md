# Deep Focus 🚀
An AI-powered task planner and focus assistant built with Next.js, Tailwind CSS, Google Gemini API, and integrated with RevenueCat billing for the Ship-A-Ton Hackathon (New Gen / Student Category).

## Features
- **AI Task Breakdown**: Instantly converts complex user goals into actionable steps using the Google Gemini API.
- **Interactive Focus Sessions**: Custom timers with task tracking and built-in focus sound effects to maintain deep concentration.
- **Live Reactivity & Stats**: Real-time tracking of daily focus sessions, total minutes, and weekly progress.
- **Monetization**: Fully integrated RevenueCat SDK with a polished Paywall modal.

## Tech Stack
- **Framework**: Next.js (App Router) & React
- **Styling**: Tailwind CSS
- **AI Integration**: Google Gemini API
- **Billing & Subscriptions**: RevenueCat SDK

## Getting Started

```bash
npm run dev
# or
yarn dev

 ```
